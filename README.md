# budget-tracker

## What is this project?
A personal budget analysis tool built with Python and Pandas.
Analyzes income and expenses from a CSV file.

## What does it do?
- Loads transaction data from a CSV file
- Calculates total income and total expenses
- Shows remaining balance

## Tools used
- Python
- Pandas

## What I learned
- How to load and analyze CSV files with Pandas
- Basic Python programming
- Using Git and GitHub
